# Как устроены сайт и бот «3D модели в Нагаево»

Полное описание системы: из чего она состоит, как ею пользоваться, где что лежит и как это чинить. Первая часть — для владельца (как пользоваться), вторая — техническая (для вас или любого другого ИИ-помощника). Актуально на 21.11.2026. Копия лежит в репозитории: `docs/ИНСТРУКЦИЯ.md` и попадает в каждую резервную копию.

# Часть 1. Как пользоваться

## 1. Коротко: как всё связано

Вы выкладываете пост в канал MAX → бот сразу запускает обновление → программа на GitHub читает канал, делает из постов карточки товаров, сжимает фото и выкладывает сайт → через 1–3 минуты товар на https://3dnagaevo.ru. Управлять всем можно из чата бота (кнопки и команды) или из приложения управления внутри MAX.

**Цепочка:** канал MAX → бот (Яндекс Облако) → обновление на GitHub → сайт 3dnagaevo.ru. Вы и админы управляете через бота и приложение управления в MAX.

Сервер нигде не арендуется: сайт хранится бесплатно на GitHub Pages, бот работает в бесплатной облачной функции Яндекса, обновления — бесплатные запуски GitHub Actions. Платный только домен (Selectel).

## 2. Как оформлять посты, чтобы они попали на сайт

- **Первая строка** — название товара.
- **«Стоимость:» или «Цена:»** — цена. Пост с ценой считается товаром. Пост без цены, размера и цвета — обычная новость, на сайт не попадает.
- **«Размер:», «Цвет:», «Материал:»** — поля карточки.
- **Хэштеги задают категорию:** `#авто`, `#игрушки`, `#антистресс`, `#фигурки`, `#декор`, `#длядома` (можно `#Для_дома` — подчёркивания не важны), `#подарки`, `#наборы`, `#геймерам`. Без тега категория угадывается по словам, иначе — «Разное».
- **Служебные теги:** `#нетнасайте` — не показывать на сайте; `#отзыв` — пост попадёт в отзывы; `#промокод` — пост с промокодом (не товар).
- **Фото поста** становятся фото товара. Ссылки из текста убираются.
- Изменили пост — изменится карточка. Удалили — товар исчезнет с сайта.

Образец поста — кнопка «📝 Шаблон» в боте или «Вставить шаблон» в приложении.

## 3. Кто может управлять

- **Владелец канала** и аккаунты, приравненные к нему (сейчас это «Амир» и «ЗD модели Нагаево»), — всё без ограничений, включая терминал и выдачу полных прав. Забрать у них доступ из бота или приложения нельзя.
- **Админы канала** — только если им дали доступ. «⭐ Полные права» — почти всё как у владельца (кроме терминала и выдачи полных прав).
- **Люди не из админов канала** — по ссылке-приглашению (см. ниже).
- **Права по разделам:** продажи и заказы, товары, посты, промокоды, отзывы, статистика, сайт (обновить, тех. работы, копия), доступ. Настраиваются кнопкой «⚙️ Права».

**Как дать доступ:**

- Админу канала — «👥 Доступ» → «Дать доступ».
- Любому другому человеку — «👥 Доступ» → «➕ Пригласить по ссылке». Выбираете разделы, получаете ссылку и пересылаете её человеку. Он открывает бота и сразу получает доступ, вам приходит уведомление. Ссылка работает 24 часа и только один раз. Не выкладывайте её в канал и группы.
- Забрать доступ — кнопка «Забрать» (с подтверждением).

## 4. Бот: меню и команды

Кнопки меню: 📊 Статус, 📈 Статистика, ✅ Продано, 🧾 Продажи, 📜 История, ↩️ Отменить, 🔥 Топ, 🔄 Обновить, 🙈 Скрыть, 👁 Вернуть, 💰 Цена, 🖼 Обложка, 💬 Отзыв, 🗂 Отзывы, 📸 Новый пост, ✏️ Изменить пост, 🎟 Промокоды, 📝 Шаблон, 👥 Доступ, 🗄 Резервная копия, 🚧 Тех. работы, 💾 Место, 📄 Договор, ❓ Помощь, 🛠 Приложение управления.

Если нажать команду без номера, бот сам спросит номер. Основные команды:

| Отзывы | `/отзыв текст` (+ фото, `№12` — привязать к модели), `/отзывы`, `/удалить отзыв 3`, `/проверка`, `/одобрить 5`, `/отклонить 5` |

Покупателю, который написал боту, отвечайте кнопкой «💬 Ответить» под его сообщением.

**Что видят покупатели.** У них своё меню: «🎁 Получить скидку», «🛍 Каталог», «📣 Канал», «✍️ Написать мастеру». Всё, что покупатель напишет, пересылается вам. Админские команды покупателям не видны.

- отзывы с сайта;
- промокоды;
- изменения каталога;
- отчёт по понедельникам;
- напоминание, если постов нет больше суток;
- пластик заканчивается;

## 5. Приложение управления

Открывается кнопкой «🛠 Приложение управления» в боте. Вкладки, на которые у админа нет прав, скрыты.

**📊 Сводка.** Продажи за 7 и 30 дней, график, популярное, отзывы на проверке, отложенные посты (с кнопкой «Отменить»). Кнопки:

- **Новый пост:** текст и фото. В поле «Опубликовать позже» можно указать время — пост выйдет сам, с задержкой до 5–15 минут.
- Тех. работы, Статус сайта, Обновить сайт, Резервная копия, 💾 Место на GitHub, Статистика, Открыть сайт.

**🧩 Товары.** Поиск и фильтры:

- **«⚠️ Проверка»** — модели без фото или цены, с коротким описанием, в категории «Разное», с одним фото.
- **«☑️ Выбрать несколько»** — разом скрыть, вернуть, изменить цену на ±% (округляется до 10 ₽), поставить метку, вернуть цены из постов.
- **«％ Цены по категории»** — поднять или снизить цены всей категории.
- **Карточка модели.** Цена и продажа. Блок «Карточка на сайте»: название, описание, категория, метка «🔥 Хит» или «Нет в наличии», 📌 закрепить вверху, себестоимость 1 шт. Меняется только сайт, пост в канале остаётся прежним; пустое поле — вернётся текст из поста. Ещё: главное фото, скрыть, изменить пост.

**🧾 Продажи.** Отметить продажу и история.

- **Финансы:** выручка, расходы, прибыль, средний чек — за этот месяц, прошлый месяц, год или всё время. Плюс полоски по 6 месяцам и топ моделей по выручке.
- Прибыль = выручка − себестоимость проданного − расходы. Цена запоминается в момент отметки продажи.
- **Расходы:** сумма, на что, дата, комментарий.
- **«📤 Выгрузить в Excel»** — файл с продажами и расходами приходит в чат бота.

**🎟 Промо.** Промокоды, новый код, автовыкладка по расписанию, скидка за подписку, проверка кода (раздел 7).

**📈 Метрика.** Посетители по дням и часам, цели, популярные модели, источники, наши ссылки (листовка, канал, бот), устройства, города, поисковые фразы.

- Периоды: сегодня, вчера, 7 или 30 дней, месяц, 90 дней, год, свой. По умолчанию открывается 7 дней.
- «Начать отсчёт с этого момента» — с двойным подтверждением.
- «Показать всё временно» и «Показывать всё».

**💬 Отзывы.** Добавить отзыв (имя, модель, звёзды, текст, фото), проверить присланные с сайта, убрать опубликованные.

**⋯ Ещё:**

- **Сайт.** Объявление вверху сайта (исчезнет само в указанную дату). Подборки на главной: своё название и отмеченные модели. «✏️ Тексты сайта»: FAQ, условия, «Своя модель», контакты.
- **Пластик.** Катушки: цвет, материал, вес, цена, порог предупреждения. Кнопки «➖ Потратил» и «✏️ Остаток». Покупку катушки можно сразу записать в расходы.
- **Доступ.** Админы, права, «Забрать», «➕ Пригласить по ссылке».
- **Уведомления.** Какие сообщения бот шлёт именно вам.
- **Журнал.** Кто и когда что менял, последние 500 действий. Видят владелец и полные права.
- **Ссылки.** Библиотека ссылок на модели из группового чата.
- **💻 Терминал.** Только для владельца и его аккаунтов (раздел 9).

## 6. Договор на оказание услуг

Бот составляет короткий договор возмездного оказания услуг (физлицо — физлицо) и присылает его в чат двумя файлами: **PDF** — переслать покупателю, **Word** — если нужно что-то поправить.

- **Подписи не нужны.** Перешлите PDF покупателю и попросите ответить «Ознакомлен, согласен». Договор считается заключённым после такого ответа или после оплаты — это прописано в самом договоре (п. 5.4).
- **Что внутри:** номер и дата, стороны, таблица «что делаем — кол-во — цена — сумма», итог прописью, предоплата и остаток, срок, способ получения, особенности 3D-печати (слои, допуски ±0,5 мм, оттенок), бесплатная переделка брака в течение 7 дней, отказ от заказа по ст. 782 ГК РФ, файлы заказчика.
- **В приложении:** «Продажи» → «📄 Договор на оказание услуг». Заполните заказчика (можно оставить пустым), добавьте модели с сайта (цена подставится сама) или услуги со своей ценой, укажите срок, предоплату и получение → «Сформировать». Там же «Мои данные» (ваши ФИО, телефон, населённый пункт — заполнить один раз) и список выданных договоров.
- **В боте:** кнопка «📄 Договор» или после отметки продажи — «📄 Договор на эту продажу». Одним сообщением:

  ```
  /договор
  Заказчик: Петров Пётр Петрович
  Телефон: +7 900 000-00-00
  38 2
  12 1 250
  Моделирование по фото — 500
  Срок: 5 дней
  Предоплата: 50%
  ```

  «38 2» — модель №38, 2 шт. по цене с сайта; «12 1 250» — №12 по 250 ₽; «Название — 500» — любая услуга. Свои данные: `/договор данные ФИО; телефон; населённый пункт`. Список: `/договоры`.
- Номера договоров идут по порядку. Данные (ваши и покупателей) хранятся в зашифрованном `contracts.json`.
- Это типовой шаблон, а не юридическая консультация. Для крупных заказов текст можно поправить в Word.

## 7. Промокоды и скидки

- **Создать:** «🎟 Промокоды → ➕ Новый» → `КОД СКИДКА АКТИВАЦИИ ДНЕЙ`, например `ЗИМА15 15% 3 7`. Вместо кода можно написать `авто` — бот придумает сам.
- **Дальше:** опубликовать в канал (пост с кнопкой «📋 Скопировать промокод»), поставить в очередь автовыкладки, включить без поста или удалить.
- **Активация** засчитывается, когда заказ выполнен: после отметки продажи бот предложит «🎟 Был промокод — активировать». В посте обновится «осталось N». Когда активации кончатся, в посте появится «⛔️ Промокод больше не действует».
- **Автовыкладка:** `пт 18:00 10% 3 7` — каждую пятницу в 18:00 по Уфе.
- **Скидка за подписку:** бот проверяет подписку на канал и выдаёт личный одноразовый код, один на человека.
- **Проверка кода на сайте** ничего не списывает.

## 8. Технические работы

«🚧 Тех. работы» в боте или в приложении:

- 🟡 **Баннер** — сайт работает, сверху полоса с вашим текстом;
- 🔴 **Закрыть сайт** — посетители видят экран «Технические работы» с вашим текстом и кнопками связи (с подтверждением);
- 🟢 **Выключить**.

Вы и админы видите сайт как обычно. Включается за 1–3 минуты.

## 9. Терминал

«Ещё → 💻 Терминал» — управление всеми файлами сайта прямо с телефона. Доступен только владельцу и его аккаунтам. Команды:

| Команда | Что делает |
|---|---|
| `help` | список команд и что в каком файле |
| `ls [папка]` | файлы; нажмите на файл — откроется редактор |
| `find слово` | найти файл по названию |
| `cat файл` / `edit файл` | показать / редактировать (в редакторе есть поиск) |
| `new файл` / `rm файл` | создать / удалить (главные файлы удалить нельзя) |
| `history [файл]` | последние изменения; нажмите на строку — подставится откат |
| `restore файл версия` | вернуть файл к прошлой версии |
| `runs` / `sync` | как прошли обновления сайта / обновить сейчас |
| `/команда` | любая команда бота, например `/статус` |

**Защита от ошибок:**

- Ошибку в JSON или в коде бота терминал не даст сохранить.
- Любую правку можно откатить через `history` → `restore`.
- Правки HTML и JS терминал не проверяет — если после такой правки что-то поехало, откатите её.
- Финансовые файлы терминал показывает расшифрованными, а сохраняет снова зашифрованными.

## 10. Ваши финансы скрыты

Репозиторий на GitHub публичный — его файлы может открыть любой. Поэтому:

- **Зашифрованы:** продажи с ценами (`sales.json`), расходы и себестоимость (`finance.json`), пластик (`stock.json`), журнал действий (`log.json`). На GitHub вместо данных — набор символов, прочитать их могут только бот и приложение.
- **Открыто только то, что и так видно на сайте:** счётчики «Продано: N шт.» в `sold.json` (номер модели, количество, день — без цен и сумм).
- **Ключ** — это переменная `SECRET` в облачной функции Яндекса. Её нельзя менять и терять: без неё зашифрованные данные не прочитать. Сохраните значение `SECRET` в надёжном месте (менеджер паролей, бумага). Резервные копии тоже содержат эти файлы зашифрованными.
- **Личные промокоды** хранятся только хэшем, ссылки-приглашения — тоже.

Если когда-нибудь захотите закрыть репозиторий полностью, то для работы сайта на закрытом репозитории GitHub нужен платный тариф GitHub Pro.

## 11. Место на GitHub

GitHub бесплатный, но репозиторий и сайт стоит держать в пределах примерно 1 ГБ. Сейчас занято около 30 МБ, больше всего весят фото товаров. Этого хватит на годы.

- **Бот следит сам:** раз в сутки проверяет размер и присылает предупреждение при 60% (🟡) и 85% (🔴). Предупреждение повторяется раз в неделю, пока места мало.
- **«💾 Место»** в боте или «💾 Место на GitHub» на Сводке приложения — сколько занято, что больше всего весит и сколько занимает история изменений. Кнопки:
  - 🧹 **Убрать лишнее** — удаляет файлы, которые нигде не используются (например, фото удалённых отзывов). Фото удалённых постов синхронизация убирает сама.
  - 🗑 **Старые запуски** — удаляет журналы и архивы старых обновлений сайта (последние 30 остаются).
  - 🗜 **Сжать историю** — только владелец. На GitHub останется одна текущая версия сайта, освобождается больше всего места. Сайт, бот, продажи и настройки не пострадают, но откатить файлы к версиям до сжатия будет нельзя. **Сначала сделайте резервную копию**: в ней вся история.
- **Если место всё-таки кончилось:** GitHub перестанет принимать изменения. Новые посты не появятся на сайте, но сам сайт продолжит работать. Сделайте резервную копию, затем «Убрать лишнее» и «Сжать историю».

## 12. Частые задачи

- **Поменять телефон, ссылки, Telegram** — `config.js`, через терминал (`edit config.js`) или на github.com. Через 1–3 минуты сайт обновится.
- **Поменять тексты сайта** — приложение → Ещё → Сайт → «✏️ Тексты сайта».
- **Добавить категорию или тег** — `scripts/sync_max.py`: словари `HASHTAG_CATEGORIES` и `KEYWORD_CATEGORIES`.
- **Срочно обновить сайт** — «🔄 Обновить», `sync` в терминале или GitHub → Actions → sync → Run workflow.
- **Резервная копия сейчас** — «🗄 Резервная копия».
- **Вернуть испорченный или удалённый файл** — терминал: `history файл` → `restore`. Или из архива резервной копии.

## 13. Если что-то сломалось

1. **Сайт не обновляется.** Терминал → `runs` или GitHub → Actions. Красный крестик — открыть лог. Обычно это временный сбой MAX или GitHub, следующий запуск проходит сам. Если пишет про токен — истёк `MAX_TOKEN`.
2. **Бот не отвечает.** Яндекс Облако → функция → Логи. Проверить: `адрес_функции?check=SECRET`; переподключить: `?setup=SECRET`.
3. **Приложение пустое или с ошибкой.** На экране будет текст ошибки. Полностью закройте MAX и откройте заново.
4. **Сайт не открывается по домену.** DNS в Selectel и GitHub → Settings → Pages (домен 3dnagaevo.ru, Enforce HTTPS).
5. **Пустая Метрика в приложении.** Нет или истёк `METRIKA_TOKEN` в функции.
6. **Предупреждение о месте на GitHub** — раздел 11.
7. **Бот пишет «Не удалось расшифровать данные».** Изменили `SECRET` — верните прежнее значение.
8. **Полный крах или новый аккаунт.** Восстановить из резервной копии: инструкция внутри архива, файл «ПРОЧИТАЙ_МЕНЯ.txt».

**Шифрование** (`yandex/bot.py`: `PRIVATE`, `seal`, `unseal`):

- Ключ выводится из `SECRET`: SHA-256 → HMAC-ключи для шифрования и проверки.
- Данные сжимаются zlib и шифруются потоком HMAC-SHA256 в режиме счётчика со случайным nonce. Целостность проверяет HMAC (encrypt-then-MAC). Используется только стандартная библиотека Python.
- Формат файла: `{"encrypted": "…", "v": 1, "n", "c", "t"}`.
- `gh_file` и `gh_put` расшифровывают и шифруют прозрачно. Открытые файлы шифруются при первом открытии приложения (`migrate_private`).
- После каждой записи `sales.json` бот обновляет `sold.json`. Синхронизация (`scripts/sync_max.py`) берёт счётчики оттуда и зашифрованный `sales.json` не трогает.

## 18. Бот изнутри

- В облачной функции лежит только загрузчик `yandex/index.py`. Код бота `yandex/bot.py` он берёт с GitHub и проверяет обновления раз в 5 минут. Если в новой версии ошибка, продолжает работать старая.
- **Маршруты функции:**
  - вебхук MAX, подписан заголовком `X-Max-Bot-Api-Secret`;
  - `?review=1` — отзывы с сайта;
  - `?promo=1` — проверка промокода;
  - `?app=1` — API приложения;
  - `?setup=` / `?off=` / `?check=` + SECRET — подключение вебхука.
- **API приложения** (`action`):
  - `dash`, `cmd` (любая команда бота), `metrika_data`;
  - `review_add`, `post_new`, `post_schedule` / `post_unschedule`;
  - `card`, `bulk`;
  - `fin_add` / `fin_del`, `export`;
  - `stock_add` / `use` / `set` / `del`;
  - `set` (notice, collections, texts, notify);
  - `invite`;
  - `contract` (op `get` / `settings`, без op — сформировать). Генератор — `yandex/contract.py` (только стандартная библиотека: PDF со встроенным шрифтом `fonts/contract-*.ttf` — Liberation Sans, урезан до латиницы и кириллицы; .docx из XML), бот загружает его из репозитория;
  - место на GitHub — через `cmd`: `/место`, `/место очистить да`, `/место запуски`, `/место история подтверждаю` (функции `space_info`, `gh_delete_many`, `squash_history`; сжатие — коммит без родителей и принудительное обновление `main`). После сжатия локальные копии репозитория нужно обновить: `git fetch && git reset --hard origin/main`;
  - `term` (только `real`; операции ls / find / cat / write / rm / history / restore / runs / sync).
- Вход в приложение проверяется подписью MAX (initData, как в Telegram: HMAC с ключом `HMAC("WebAppData", токен)`).
- **Права:** `config()` собирает:
  - админов канала (`/chats/{id}/members/admins`) и приглашённых (`guests`);
  - `chief` — владелец, полные права, `as_owner`;
  - `real` — владелец и `as_owner`;
  - `owners` — все, у кого есть доступ;
  - `perms` по разделам: sales, items, posts, promo, reviews, stats, site, access.
- **Приглашение:** `/пригласить` или `action=invite` → ссылка `https://max.ru/se15070545_bot?start=inv_ТОКЕН`. В `access.json` хранится HMAC токена со сроком 24 часа. Событие `bot_started` с этим payload добавляет человека в `guests` и `allowed`.
- **Запасной бот** `scripts/bot.py` в синхронизации работает, только если вебхук выключен.

## 19. Автоматические процессы GitHub

- `.github/workflows/sync.yml` — запускается каждые 5 минут, при изменении кода и по команде бота. Что делает:
  - ставит сертификаты Минцифры (нужны для API MAX);
  - раз в сутки проверяет место на GitHub (`maybe_space_warning`);
  - запускает `scripts/sync_max.py`;
  - коммитит данные;
  - выкладывает сайт на Pages. Если GitHub не находит архив сайта, выкладка повторяется через 30 секунд.

  Изменения `links.json`, `promos.json`, `settings.json`, `finance.json`, `stock.json`, `log.json` сами по себе синхронизацию не запускают.
- `.github/workflows/backup.yml` — по воскресеньям около 20:17 по Уфе и по кнопке. Собирает архив (все файлы и полная история git) и присылает в бота.

- **Ограничения РФ:** Cloudflare и Netlify ненадёжны, поэтому GitHub Pages + Яндекс Облако. 152-ФЗ — плашка cookies и политика.
- **Стиль сайта:** шрифты Unbounded + Onest, кобальт #2F4BFF, оранжевый #FF6B2C, чернила #1B1F3B, фон #EEF0F4.

- Перед пушем делать `git pull --rebase`: бот и синхронизация коммитят сами.
