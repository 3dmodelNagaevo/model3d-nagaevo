ЧТО ВНУТРИ
----------
1. Папка «сайт_и_бот» — всё, что сейчас лежит на GitHub:
   • index.html, privacy.html, config.js — сам сайт (откройте index.html в браузере,
     чтобы посмотреть; каталог подгрузится, если открыть через любой простой веб-сервер)
   • photos/        — все фото товаров (сжатые копии из канала)
   • m/             — страницы отдельных моделей (для ссылок и поисковиков)
   • img/, qr/      — картинки сайта, QR-коды
   • catalog.json   — весь каталог: названия, цены, описания, просмотры
   • sales.json     — отметки о продажах
   • reviews.json   — отзывы (и ожидающие проверки)
   • promos.json    — промокоды, расписание автовыкладки, скидка за подписку
   • links.json     — библиотека ссылок на модели из группового чата
   • overrides.json — скрытые товары, цены и обложки, заданные через бота
   • access.json    — кому из админов разрешён бот
   • state.json, channel_id.txt, outbox.json — служебные данные синхронизации
   • scripts/       — программа синхронизации канала с сайтом (GitHub Actions)
   • yandex/        — код бота: bot.py (сам бот) и index.py (загрузчик для Яндекс Облака)
   • .github/workflows/sync.yml — автозапуск синхронизации каждые 5 минут
   • CNAME, sitemap.xml, robots.txt, yandex_*.html — домен и файлы для Яндекса

2. Файл «история_изменений.bundle» — полная история всех изменений (git).
   Из него можно восстановить сайт на любой дате.

ЧЕГО ЗДЕСЬ НЕТ (храните отдельно, в надёжном месте!)
------------------------------------------------------
Секретные ключи в копию специально не попадают:
   • MAX_TOKEN       — токен бота MAX (dev.max.ru → ваш бот)
   • GITHUB_TOKEN    — ключ доступа к GitHub (для бота в Яндекс Облаке)
   • SECRET          — секрет вебхука бота (он же в ссылке ?setup=...)
   • METRIKA_TOKEN   — токен отчётов Яндекс Метрики (если задавали)
Они записаны: в GitHub (Settings → Secrets and variables → Actions)
и в Яндекс Облаке (функция max-bot → Редактор → Переменные окружения).

Также не входят настройки сервисов (они живут у самих сервисов):
   • домен 3dnagaevo.ru и DNS-записи — в Selectel
   • GitHub Pages (Settings → Pages → Custom domain 3dnagaevo.ru, Enforce HTTPS)
   • функция в Яндекс Облаке: id d4ep1v6rng97936ssn5p
   • счётчик Яндекс Метрики 114366870, Яндекс Вебмастер

КАК ВОССТАНОВИТЬ, ЕСЛИ ЧТО-ТО ПРОПАЛО
-------------------------------------
• Пропал один файл (например, промокоды или продажи):
  на GitHub откройте репозиторий → Add file → Upload files →
  загрузите нужный файл из папки «сайт_и_бот» → Commit changes.
  Через 1–5 минут сайт и бот подхватят его.

• Пропал весь репозиторий / новый аккаунт GitHub:
  1) создайте новый публичный репозиторий;
  2) загрузите в него всё содержимое папки «сайт_и_бот» (включая скрытую папку .github);
  3) в Settings → Secrets добавьте MAX_TOKEN; в Settings → Pages выберите
     GitHub Actions и укажите домен 3dnagaevo.ru;
  4) если имя репозитория изменилось — в Яндекс Облаке у функции поменяйте
     переменную REPO и GITHUB_TOKEN;
  Либо просто пришлите этот архив Claude — он всё восстановит.

Совет: делайте такую копию раз в месяц и храните на компьютере + на флешке/облаке.
