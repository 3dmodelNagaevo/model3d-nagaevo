# Сайт «3D модели Нагаево на заказ»

Сайт: https://3dmodelnagaevo.github.io/model3d-nagaevo/

Каталог сам пополняется из канала MAX. Каждые ~15 минут GitHub запускает синхронизацию.

## Какие посты попадают на сайт

- **Товар** — пост со строкой «Стоимость:» (или «Цена:») или с хэштегом `#каталог`.
  Первая строка поста становится названием, фото подтягиваются автоматически.
- **Категория** задаётся хэштегом: `#авто`, `#антистресс`, `#игрушки`, `#фигурки`, `#декор`, `#дом`, `#подарки`, `#геймерам`.
  Если хэштега нет, категория угадывается по словам из поста.
- **Отзыв** — пост с `#отзыв`. Он попадает в раздел «Отзывы» (лучше с фото).
- **`#нетнасайте`** — пост не попадает на сайт.
- Если изменить пост, сайт обновится. Если удалить пост (даже старый), товар уйдёт с сайта.

## Бот (пишите ему в личку в MAX)

Бот слушается только владельца и админов канала. Отвечает в течение 15–30 минут.

| Команда | Что делает |
|---|---|
| `/помощь` | список команд |
| `/статус` | сколько товаров на сайте, что скрыто |
| `/топ` | популярное за неделю (по просмотрам постов) |
| `/стата` | статистика за неделю |
| `/скрыть 12` / `/показать 12` | убрать или вернуть товар №12 на сайте (пост остаётся) |
| `/цена 12 300` / `/цена 12 сброс` | поменять цену на сайте или вернуть цену из поста |
| фото + подпись `/пост …` | опубликовать товар в канал, а оттуда он попадёт на сайт |

Пример подписи для `/пост`:
```
/пост Дракон-антистресс
Цена: 200
#антистресс
```

Бот сам присылает:
- ✅ уведомление о новом товаре на сайте;
- 🗑 уведомление об удалённом товаре;
- ⚠️ предупреждение о посте без цены;
- 📅 **отчёт по понедельникам**.

## Настройки

- `config.js` — телефон, ссылки, Telegram-канал, номер счётчика Яндекс Метрики.
- Секрет `MAX_TOKEN` — токен бота.
- Необязательно: переменная `METRIKA_ID` и секрет `METRIKA_TOKEN`, чтобы в отчёте была статистика Метрики.

## Файлы

- `index.html` — сайт, `m/N.html` — страницы товаров (для превью ссылок), `privacy.html` — политика.
- `catalog.json` — каталог (генерируется), `state.json` — служебное состояние бота.
- `photos/` — фото из постов (сжатые), `photos/t/` — миниатюры, `qr/` — QR-коды.
- `scripts/` — синхронизация (`sync_max.py`), бот (`bot.py`), страницы (`pages.py`).
