# Сайт «3D модели Нагаево на заказ»

Каталог сам пополняется из канала MAX: выложили пост с ценой, и через 15–30 минут модель появилась на сайте.

## Как это устроено

- `index.html` — сайт. Каталог он берёт из `catalog.json`.
- `scripts/sync_max.py` — читает посты канала через бота MAX и обновляет `catalog.json` и папку `photos/`.
- `.github/workflows/sync.yml` — запускает скрипт каждые 15 минут и выкладывает сайт на GitHub Pages.
- `img/` — фото для товаров, добавленных вручную.

## Какие посты попадают на сайт

Попадает пост, в котором есть строка **«Стоимость:»** (или «Цена:»), **или** хэштег **#каталог**.

```
BMW M4 (G82)
- Размер: (по желанию)
- Цвет: согласовывать в ЛС
- Стоимость: 1000 ₽
#авто
```

- Первая строка становится названием, остальные строки без «Размер/Цвет/Стоимость» — описанием.
- Фото из поста скачиваются автоматически.
- Категорию задаёт хэштег: `#авто`, `#антистресс`, `#игрушки`, `#фигурки`, `#декор`, `#дом`, `#подарки`, `#геймерам`.
  Без хэштега категория угадывается по словам; если не угадалась, товар попадает в «Разное».
- **`#нетнасайте`** — пост никогда не попадёт на сайт.
- Изменили пост — изменения придут на сайт. Удалили пост — товар уйдёт с сайта.

## Ручные товары

Их можно добавить в `catalog.json`, указав `"source": "manual"` (пример: волчок и катана). Скрипт их не трогает.

## Если что-то сломалось

Откройте вкладку **Actions**, затем последний красный запуск и шаг «Забрать новые посты из канала». Там написано по-русски, что не так:

- **401** — токен неверный или перевыпущен. Обновите секрет `MAX_TOKEN`.
- **403 / «бот не видит ни одного канала»** — бот не администратор канала.
- **«Не удалось обратиться к API MAX»** — MAX не пустил запрос с серверов GitHub.
